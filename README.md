# EEG 안구 성분 기반 ADHD 분류

19채널 EEG에서 ICA로 분리한 **안구(ocular) 성분을 아티팩트로 버리지 않고** ADHD 분류의 특징으로 활용하는 연구입니다. 표준 전처리 파이프라인은 안구 성분을 제거하지만, 이 연구는 안구 활동(눈 움직임·깜빡임 패턴)이 ADHD군과 대조군을 구분하는 정보를 담고 있다고 보고, 이를 신경 특징과 결합했을 때 신경 특징만 쓸 때보다 분류 성능이 향상되는지를 검증합니다.

## 데이터

- **출처:** Nasrabadi et al., IEEE DataPort (DOI: [10.21227/rzfh-zn36](https://doi.org/10.21227/rzfh-zn36))
- **구성:** 7–12세 아동 121명 (ADHD 61 / 대조군 60), 시각 주의 과제 중 측정
- **사양:** 19채널 (standard 10-20), 128Hz, 귓불(A1/A2) 참조, 원시 미가공 신호

> **주의:** 데이터 파일(`.mat`)은 용량과 라이선스 문제로 이 저장소에 포함되지 않습니다 (`.gitignore`로 제외). 코드를 실행하려면 위 DOI에서 직접 내려받아야 합니다.

## 실행

각 파일은 단독 실행하면 해당 단계까지 검증하도록 작성되어 있습니다.

```bash
python src/load_data.py     # 적재 검증 (121명 전원 적재·좌표 매칭 확인)

```

각 파일이 정확히 무엇을 하는지는 파일 상단의 docstring을 참고하세요.

## 방법론 메모

- **피험자 단위 교차검증:** 세그먼트 단위 분할은 정확도를 부풀리므로, 평가는 반드시 피험자 단위로 분할합니다.
- **녹화 길이 보정:** ADHD군의 녹화가 체계적으로 더 길어(중앙값 약 144s vs 122s) 길이가 교란변수가 될 수 있으므로, 안구 특징은 횟수가 아닌 **비율(rate) 기반**으로만 산출합니다.
- **세 가지 비교 조건:** 신경 특징만 / 안구 특징만 / 결합 — 모두 sensor space에서 back-projection으로 구성하여 공정하게 비교합니다.

## 한계

- ICLabel은 19채널·귓불 참조·아동 데이터에서 분포 밖(out-of-distribution)일 수 있어, 성분 판정 시 토포그래피·시계열 기준으로 교차 검증이 필요합니다.
